# 🧬 DevDNA

**Descubra o que seus códigos dizem sobre você.**

Uma ferramenta que analisa perfis do GitHub e transforma repositórios, linguagens e atividade de desenvolvimento em um DNA tecnológico visual.

### ◈ Funcionalidades

- **Análise de perfil** — explore dados públicos de desenvolvedores.
- **DNA tecnológico** — visualize as linguagens presentes nos projetos.
- **Arquétipo de desenvolvedor** — descubra o perfil técnico identificado pela análise.
- **Dashboard interativo** — acompanhe repositórios, estrelas, forks e atividade.
- **Relatório em PDF** — exporte os resultados da análise.

### ◈ Tecnologias

`React` `TypeScript` `Vite` `Node.js` `Fastify`

### ◈ Arquitetura

- **Frontend:** Vercel
- **Backend:** Render
- **Dados:** GitHub API
